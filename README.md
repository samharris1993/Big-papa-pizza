# Big Papa Pizza — Simple Ordering System

This version has NO online payment.

Customers can:
- Choose pizzas and quantities
- Choose Collection or Delivery
- Enter their details, requested time, address and notes
- See the total
- Submit the order

Orders are submitted to Netlify Forms.

In Netlify, open your site and go to:
Forms → pizza-orders

There are no Stripe keys, payment functions, webhooks or payment setup required.

Submitting the form records the order request. It does not charge the customer.
